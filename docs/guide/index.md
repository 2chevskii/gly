# Guide

`gly` adds icons and colors to file and folder listings in PowerShell 7.0 or later. It works with your usual file commands and provides list, tree, and grid layouts.

Start with [Installation](installation.md), then follow the [Quick Start](quick-start.md).

## Make It Yours

- [Configuration](configuration.md): change colors, symbols, sizes, and dates.
- [Themes](themes.md): choose and preview a color palette.
- [Glyph sets](glyph-sets.md): choose the symbols shown beside file names.
- [Layouts](renderers.md): display files in a list, tree, or grid.
- [Custom rules](selectors.md): match files by name, extension, or attributes.

Settings apply to the current session. Add your preferred commands to your [PowerShell profile](installation.md#load-gly-in-every-session) to reuse them each time you open PowerShell.

If something looks wrong, see [Troubleshooting](../troubleshooting/index.md). [Limitations](../limitations/index.md) explains the supported behavior.
